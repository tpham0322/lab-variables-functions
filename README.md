# JavaScript Functions Assignment

## Overview
This project demonstrates the use of JavaScript functions, parameters, conditional logic, input validation, and mathematical calculations. The program collects user input through browser prompts and displays the results using alert messages.

## Features

### Task 1: Format Full Name
- Accepts a first name and last name.
- Capitalizes the first letter of each name.
- Returns the name in the format:
  - `LastName, FirstName`
- Validates that both names are entered.

### Task 2: Calculate Total Cost
- Accepts a price, quantity, and tax rate.
- Calculates the total cost using:
  - `(price × quantity) × (1 + taxRate)`
- Validates that all inputs are valid numbers.

### Task 3: Check Eligibility
- Determines eligibility based on age and employment status.
- Returns one of the following:
  - Eligible
  - Conditionally Eligible
  - Not Eligible

### Task 4: Calculate Total Cost with Discount
- Adds an optional discount parameter.
- Calculates the total using:
  - `((price × quantity) - discount) × (1 + taxRate)`
- If no discount is provided, the calculation is performed without a discount.

## Technologies Used
- HTML5
- JavaScript (ES6)

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Follow the prompts.
4. Results will be displayed in alert boxes.

> **Note:** This project uses the browser's `prompt()` function and should be run from an HTML page, not with Node.js.
